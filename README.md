# Qwen Image 工作台

Vue 3 生图工作台，支持本地 ComfyUI / Qwen Image 2.1 和 GPT Image 2 / 2.5 Images API。主表单使用顶部所选引擎，画布文字节点和参考图编辑可独立选择模型；支持历史重试、单个任务取消、项目保存和导入导出。

支持多个任务同时提交和独立追踪。在任务生成期间，主表单、其他文本节点和图片编辑仍可添加任务；同一个节点在提交响应返回前会短暂禁用，防止重复提交。每个任务独立恢复、取消、重试和显示结果。当前单个本地 ComfyUI 进程按队列依次推理；多个任务在工作台中同时进行管理，不表示多张图片同时占用 GPU 推理。

## 在无限画布生成视频

打开“节点画布”，点击顶部“视频节点”，或右键选择“增加视频节点”。已有图片节点也可点击“用这张图生成视频”，自动连接参考图。填写画面描述，选择清晰度、时长和画面比例，再点击“生成视频”。也可不连接参考图，直接描述场景。

| 清晰度 | 9:16 竖版  | 16:9 横版  | 1:1 方形  |
| ------ | ---------- | ---------- | --------- |
| 480P   | 480 × 854  | 854 × 480  | 480 × 480 |
| 720P   | 720 × 1280 | 1280 × 720 | 720 × 720 |

参考图自动完整保留并补齐背景。视频节点保留参考图、画面描述、清晰度、时长和比例，不再显示中文口播及参考图构图选项，旧节点中这两项的值也不会用于新生成任务。视频采用 24 fps；选择 4/6/8/10 秒后，实际时长会按模型帧数网格向上取整为约 4.5/6.6/8.0/10.1 秒。旧任务未记录比例时按 16:9 恢复；重试保留原任务参数。

“画面描述”默认描述镜头、人物与动作，不会把整段文字当作口播脚本。需要口播时明确写“口播：大家好，我是小雅。”或“人物说：……”；需要唱歌时写“边跳边唱：……”或“歌词：……”。明确的台词与歌词分别按说话、演唱处理，音乐、动作和运镜遵循画面描述，不再套用固定的主持人微笑、轻微动作和固定镜头。否定要求（如“不要口播”）不启用说话。提示词处理依据 [ComfyUI H3 提示词说明](https://docs.comfy.org/tutorials/video/minimax/minimax-h3-prompt-guide)，模型的最终表现仍需查看成片。

中文场景说明先用本地 CPU 翻译成英文，只把明确指定的中文台词、歌词保留在 `<d>` 中，避免模型把中文动作描述念出来。翻译失败会停止提交，不会回退为原始中文画面描述。用户原文和转换后的 `sceneEnglish` 都保存在任务中供检查。翻译使用 [Helsinki-NLP/opus-mt-zh-en](https://huggingface.co/Helsinki-NLP/opus-mt-zh-en)（CC-BY-4.0，赫尔辛基大学语言技术研究组），权重放在 `.data/video-translation`；需要已有 PyTorch/Transformers 的 Python 环境及 `sentencepiece`、`sacremoses`。可用 `VIDEO_TRANSLATOR_PYTHON` 指定 Python、`VIDEO_TRANSLATOR_MODEL` 指定模型目录。运行时离线，不传输描述，也不调用付费接口；迁移工作台时需一起迁移翻译权重及 Python 依赖。

生成任务显示真实采样步数、等待时间，支持单独取消。完成后可直接在结果节点播放、下载 MP4，并在右侧“视频库”找回任务。关闭画布或刷新页面不会取消任务；项目保存、导入导出同时保留视频节点和任务引用。迁移实体视频时还需复制 ComfyUI 的 `output/video/qwen-workbench` 目录。

视频使用已安装的本地 MiniMax H3 模型，与生图页面所选的本地/API 引擎独立。本地视频和图片共用 ComfyUI 队列，依次执行。720P 在 8GB 显存机器上耗时明显更长，建议先用 480P 测试。两档均按对应画面尺寸推理：模型内部使用 32 像素网格的 864 × 480 / 1280 × 736，解码后整理为标准输出尺寸；不是把 288P 成片放大。使用基础模型 12 步采样，视频 VAE 分块解码，原生生成立体声。人物外观和动作效果仍需查看成片。

视频工作流位于 `workflows/minimax-h3.json`，参数位于 `shared/video.mjs`，服务接口为 `/api/videos/config`、`/api/videos/generate`、`/api/videos/jobs`、`/api/videos/jobs/:id`、`/api/videos/jobs/:id/cancel` 和 `/api/videos/media/:id`。播放接口支持 Range 请求和下载，任务保存在现有 SQLite 数据库中，图片接口不混入视频记录。没有增加付费 API，也不自动下载视频模型；缺少模型或节点时会提示未就绪。模型及节点要求见 [ComfyUI MiniMax H3 官方说明](https://docs.comfy.org/tutorials/video/minimax/minimax-h3)。运行 `npm run test:video` 检查参数验证、工作流、任务状态、定向取消和视频读取，`npm run check` 检查服务语法并构建前端。

## 使用 API 生图

打开图像工作台顶部的 **生图配置**，选择 **API 模型**，填写服务地址和密钥，选择模型后点击“保存并使用 API”。API 地址与密钥由工作台和画布共用，并保存在本机，重新启动后自动恢复。工作台与画布都保留“本地 / API”和模型的快捷切换入口；画布顶部设置用于新节点的默认模型，已有文字节点各自保留选择。从画布进入配置，关闭后返回画布。本地环境检查、ComfyUI 安装、模型下载和试生成可从“生图配置 → 本地模型 → 配置本地环境”进入。

默认 API 地址为 `https://api.openai.com/v1`，支持兼容 OpenAI Images API 的 HTTPS 服务，本机服务可以使用 HTTP。API 模型提供 `gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst`，不再显示日期快照选项。旧快照任务记录仍可读取，再次生成时使用同系列的当前模型。低于 2 的模型不能选择或提交；不使用含糊的 `gpt-image-2.5` 模型名。切回“本地”即可继续使用原有 ComfyUI；使用 API 时无需本地显卡、Python、ComfyUI 或模型下载。

“保存并获取模型列表”访问服务的 `/models`，显示实际返回的生图模型，不调用生图接口，不产生图片。预置选项不代表当前账户已有模型权限；检查通过也不保证尺寸、质量生效，实际生图权限、额度及账单以 API 服务为准。换服务地址时必须重新填写该服务的密钥或清除原密钥，避免把旧服务的密钥带到新地址。第三方兼容服务需支持 `/images/generations`、`/images/edits` 和 base64 图片响应；请求会明确指定 `response_format=b64_json`，直连 OpenAI 使用其默认 base64 返回格式。

- **任务与切换**：每个任务保存自己的引擎、模型、质量和尺寸；运行中切换引擎、模型或密钥不改变已提交任务。API 最多同时执行 3 个请求，额外任务排队，支持与本地任务同时管理。历史重试使用原任务的引擎和模型、当前配置的 API 地址与密钥。
- **节点模型**：文字节点的“模型”下拉框分为本地 Qwen 和 GPT Image 2 系列 API 两类，同一画布可以混用。比例和质量随该节点模型适配，模型选择随项目保存、导出和恢复。旧文字节点首次打开时采用当前默认模型；图片编辑默认继承来源图片的模型，也可以单独切换，不改动原图或其他节点。未配置 API 密钥时仍可使用本地节点。
- **画布图片**：工作台生成的图片保留在历史记录和图片库中，进入画布时不自动添加。需要时从图片库点击“放入画布”或拖入；通过画布节点生成的结果显示在对应的输出节点中。
- **清空画布**：顶部“清空画布”移除所有节点和连线，并恢复默认视角，历史记录、图片库和正在生成的任务继续保留。本次打开期间、添加新节点之前可点击“撤销清空”恢复；清空后的画布自动保存。
- **图片与编辑**：参考图先保存到工作台，API 编辑不依赖 ComfyUI；本地编辑提交时再上传到本地引擎。两种引擎生成的图片都可以作为下一次编辑的参考图。API 结果保存在 `.data/api-images/output`，参考图位于 `.data/api-images/input`，缩略图位于 `.data/api-images/thumbnails`，之后查看和下载不需要 API 服务在线。
- **参数**：GPT Image 2 的“草稿 / 标准 / 高质量”分别使用 `low / medium / high`。2.5 另提供“自动 / 极高 / 最高”（`auto / xhigh / max`），工作台、节点和参考图编辑随所选模型显示可用选项；切回本地或 GPT Image 2 时，无效质量自动恢复为标准，原任务与历史重试仍保留原模型、质量。API 原生生成大图，不使用本地超分，也不支持随机种子；反向提示词会作为“请避免以下内容”补充到主提示词。所有预设满足 16 像素对齐、3840 最大边和 8,294,400 总像素限制；高于 2560 × 1440 的尺寸属于官方实验范围。以实际返回图片的尺寸展示结果。参数依据 [OpenAI 图像生成文档](https://developers.openai.com/api/docs/guides/image-generation)。
- **密钥**：只保存在本机 `.data/api-engine.json`，不返回给浏览器，不写入任务、画布、浏览器备份或项目导出。该本机文件含明文密钥，请只向可信账户开放项目数据目录，不要提交或分享它。也支持 `OPENAI_API_KEY`、`OPENAI_BASE_URL`；环境变量密钥仅用于匹配的初始服务地址，已保存密钥优先。
- **结果展示**：原样发送官方 `size`、`quality`，结果按实际像素显示尺寸和比例。API 结果不显示返回质量标签或参数差异提示；生成时的质量选择仍用于提交请求。
- **取消与恢复**：排队任务取消后不发起 API 请求；执行中的任务取消后停止等待，远端可能继续处理并计费。等待超时默认 15 分钟，可用 `GPT_IMAGE_TIMEOUT_MS` 修改。工作台重启后，将中断的 API 任务标记为失败，不自动重新调用付费接口；请查看服务记录后决定是否重试。

## 环境与运行

### 换一台 Windows 电脑

把项目源码放进新电脑的一个可写文件夹，双击 `start-workbench.bat`。首次启动会准备 Node.js 24（已有合适版本则复用）、安装工作台依赖、构建页面并打开浏览器。Node.js 来自官方站点并核对 SHA-256；便携运行环境保存在 `.run/node`，不修改系统 Node.js。首次运行需要能访问 nodejs.org 和 npm 注册表。

新电脑选择本地引擎且环境未配置好时会自动打开“本地配置”，之后也可以通过顶部“生图配置 → 本地模型 → 配置本地环境”进入。若打算使用 API，可先关闭本地配置向导，在“生图配置”中选择 API 模型并填写密钥。已保存 API 选择的电脑再次打开时不会自动弹出本地配置向导。

1. **检查这台电脑**：读取显卡、NVIDIA 驱动、显存、系统内存、目标磁盘可用空间；已有 Python 时运行一次 PyTorch CUDA 运算，并检查 ComfyUI 的必要节点。显存 8 GB 的电脑需要实测，建议 32 GB 以上系统内存、至少 25 GB 安装空间；这些是本工作台的经验建议，最终以试生成结果为准。
2. **配置 ComfyUI**：Windows x64 / NVIDIA RTX 可下载并解压经过校验的官方便携版，包含 Python 和 PyTorch。选择安装父目录，界面会新建 `ComfyUI_windows_portable`，不会覆盖已有安装。已安装桌面版、便携版或手动版，可填写本机服务地址、数据目录、`main.py` 和 Python 完整路径。RTX 10 系列及其他显卡请用官方对应安装方式，然后连接已有服务。AMD、Intel、Mac 不在当前自动安装与试生成向导的验证范围内。
3. **准备模型**：下载 Qwen-Image 2.1 的主模型、文本/参考图编码器及 VAE，三个必需文件共约 14.2 GB（13.3 GiB）。每个文件显示来源、许可、安装位置和状态，支持逐个下载、中断续传及 SHA-256 校验。可选的 UltraSharp 仅用于超分档，许可为 CC-BY-NC-SA-4.0，不影响普通生成。自定义模型由用户自行提供，默认清单固定仓库版本与哈希。
4. **启动与验证**：启动或连接本地 ComfyUI，检查模型是否被引擎识别、节点是否齐全。点击“开始试生成”会实际生成一张 1024 × 1024 的红色陶瓷杯图片，使用真实工作流及 25 步采样；界面会读取并解码图片、检查尺寸，显示结果和耗时。查看画面后点击确认，才显示“已验证”。文件和节点存在不等于模型能推理。

ComfyUI 安装包和模型分别从 GitHub 官方仓库、Hugging Face 模型仓库下载，需要能够访问这些站点。工作台支持启动环境的 `HTTP_PROXY` / `HTTPS_PROXY`，也可在配置步骤的“下载网络设置”中填写本机 HTTP 代理地址，例如 `http://127.0.0.1:7890`，然后保存；本机引擎连接始终绕过代理。下载失败会保留 `.part` 文件，重试时续传；损坏的下载移到 `.invalid-*` 备份。已存在但不匹配的完整文件不会被覆盖，需要先手动备份再重新下载。安装中断的 `.qwen-install-*` 临时目录也会保留。下载和校验时有进度、取消与日志；关闭配置界面后任务仍在后台继续，关闭工作台进程则会中断，重新打开可重试。

本机路径、服务地址和低显存选项保存在 `.data/runtime.json`，保存后工作台立即使用新地址。当前有生成任务时不能修改路径、下载/校验模型或停止引擎；不会中断其他任务。低显存选项需要由工作台重新启动引擎才会生效。工作台只停止当前进程自己启动的引擎；外部启动的 ComfyUI 请从原窗口管理。引擎日志保存在 `.data/comfy-engine.log`。

### 迁移已有图片与记录

- 只迁移代码：不复制 `node_modules`、`dist`、`.run`，在新电脑双击启动入口即可重新准备。
- 保留任务与画布：关闭旧电脑工作台后复制 `.data/workbench.sqlite`、`.data/api-images`，以及 ComfyUI 数据目录中的 `input/qwen-workbench`、`output/qwen-workbench`；已有模型也可以复制对应的 `models` 子目录，避免再次下载。不要把旧电脑的 `.data/runtime.json` 当成新电脑配置直接使用。API 密钥建议在新电脑界面重新填写，不随公开源码或项目导出迁移。
- 项目 JSON 导出只包含图片引用，不含图片实体；单独导出 JSON 不足以迁移图片。新电脑完成路径配置后再导入项目。

官方资料：[ComfyUI 便携版安装](https://docs.comfy.org/installation/comfyui_portable_windows)、[硬件与系统要求](https://docs.comfy.org/installation/system_requirements)、[Qwen-Image 2.1 模型](https://huggingface.co/Comfy-Org/Qwen-Image-2.1)。模型与安装清单记录在 `shared/setup-manifest.json`，核对日期为 2026-10-03。

### 已配置好环境的手动启动

- Node.js 24.14 或更新版本（使用内置 SQLite 及原生下载代理支持）。
- 已启动的 ComfyUI，默认地址为 `http://127.0.0.1:8000`。
- 模型与 `TextEncodeQwenImage21` 节点，可通过 ComfyUI `/object_info` 检查。

```powershell
npm ci
npm start
```

打开 `http://127.0.0.1:3788`。`npm start` 会先构建 Vue 前端。开发时，单独运行 `node server.js` 提供接口，再运行 `npm run dev` 启动 Vite 热更新页面。

```powershell
.\services.bat status all
.\services.bat start all
.\services.bat restart web
```

`restart-all.bat` 使用相同的服务管理器。管理器只操作命令行中包含确切项目脚本路径的进程，不会按端口强杀其他程序。升级前已经手动启动的相对路径命令需要在原终端结束一次，然后改用服务管理器启动。

## 配置

`shared/config.json` 是前后端共用的比例、像素、质量、模型和采样配置。本机路径通过“环境配置”保存到 `.data/runtime.json`，启动脚本也读取它。未保存时使用用户目录下的便携版路径；为兼容原工作站，会检测原有 `D:/comfyui` 桌面安装。

支持环境变量：`PORT`、`COMFYUI_BASE_URL`、`DATA_DIR`、`COMFY_TIMEOUT_MS`。`WORKBENCH_CONFIG` 可指向一个 JSON 配置覆盖文件；模型与采样字段会与默认值合并。环境变量/覆盖文件提供初始默认值，已保存的本机配置优先；修改采样、模型等静态配置后重启服务。

本地质量档位显示为“快速 / 精细 / 超分”。内部仍保留 `1K / 2K / 4K` 标识，以兼容旧记录；精细档最长边为 1472–1664 像素，超分档为 3840–4096 像素。API 使用相同的存储标识，但按 `shared/api-image.json` 显示对应质量、尺寸并原生生成。界面始终显示实际输出尺寸。

没有反向提示词时使用默认 CFG 1。填写反向提示词时启用 `sampler.negativeCfg`（默认 3），让负向条件实际参与采样；这可能增加推理时间与显存需求。参考图按目标比例居中裁切，之后按原生编辑所需尺寸对齐，最后恢复规定的输出尺寸。

## 数据与恢复

- `.data/workbench.sqlite` 保存任务参数和项目画布，使用事务和版本检查，服务重启后仍可读取。
- `.data/thumbnails` 保存生成的缩略图。原图代理采用流式读取，超时覆盖响应体。
- 浏览器备份保存未写完的更新，刷新时会恢复；旧版的浏览器历史和画布会自动迁移。
- 历史保存不再限制为 12 条；界面按页显示。项目安全容量上限为 10000 个任务、10000 个节点及 20000 条连线，JSON 导入上限为 16MB。
- 导出项目为 JSON，包含提示词、任务参数、节点、连线、位置和图片引用。图片实体保存在 `.data/api-images` 和 ComfyUI 的 input/output 目录；跨电脑迁移时应同时备份对应图片目录和模型配置。
- 移除历史只隐藏记录，保留原图；运行中的隐藏任务仍会被独立追踪。“取消任务”会删除排队项，并针对该任务发送中断，不使用全局中断。存在运行、排队或正在提交的任务时，项目导入会等待这些任务结束，以保留任务与节点的关联。
- 多窗口同时修改时，旧版本保存会被拒绝。界面会提示冲突，保留当前备份和导出能力；导出后重新载入可读取最新版本，避免静默覆盖。

状态读取断线会自动退避重试，不会把 GPU 任务误判为失败。不存在的任务、中断和执行异常都有明确终态。参考图上传中刷新时，节点会恢复为可重新上传状态。

## 节点画布

右键创建文本或图片节点。文本节点按 Enter 运行，Shift+Enter 换行。将图片节点连入文本节点后，运行时使用该图片作为参考；每个文本节点可连接一张参考图。生成结果自动创建节点并连线。图片节点可放大预览或继续编辑。

文字节点和图片编辑使用统一的参考图区域、提示词输入区及生成参数面板。文字节点会预览已连接的参考图；点击缩略图右上角的移除按钮可断开参考图连线。参数按钮集中设置比例和输出质量，并显示实际输出尺寸；Esc 或点击面板外关闭参数。提示词区域支持滚动和调整高度，不会触发画布缩放。

拖动空白处平移、滚轮缩放、Delete 删除选中项。文本输入和侧边图片列表滚动不会触发画布缩放。节点采用 Vue 稳定键、缩略图、懒加载和视口筛选。

## 源码

`src/components` 放置 Vue 单文件组件；`src/composables/useWorkbench.js` 管理任务、恢复和项目保存；`src/domain.js` 管理数据规范化；`server.js` 提供接口；`lib/storage.js` 提供 SQLite 存储；`workflows/qwen-image.json` 保存工作流模板。

服务默认只监听本机回环地址。
本地 PNG、JPEG、WebP 图片可直接拖入画布上传（每张不超过 10MB，支持同时拖入多张），上传完成后成为图片节点。拖到空图片节点上会填入该节点；拖动右侧素材库仍会把已有素材放入画布。首页也可将一张图片拖到左侧生成面板，自动切换为图生图并上传参考图。上传过程显示状态，文件格式、大小或内容不正确时会提示错误。
