# Qwen Image 工作室

基于 Vue 3、Node.js 和 ComfyUI 的本机图像工作台。支持本地 Qwen Image 生图、GPT Image 2 系列 API 生图、项目画布管理，以及本地 MiniMax H3 视频生成。

首次打开默认进入工作台。项目、生成记录和素材保存在本机；刷新浏览器会恢复所在页面、当前项目和画布视角。

## 功能概览

| 功能       | 说明                                                            |
| ---------- | --------------------------------------------------------------- |
| 图像工作台 | 文生图、单张参考图编辑、比例与质量设置、历史重试、原图下载      |
| 本地生图   | 通过本机 ComfyUI 运行 Qwen Image 2.1，支持快速、精细和超分档    |
| API 生图   | 接入兼容 Images API 的服务，选择 GPT Image 2 系列模型           |
| 项目中心   | 新建、重命名、搜索、导入、导出和删除项目，每个项目有独立画布    |
| 无限画布   | 文字、图片、视频节点与连线，同一画布可混用本地和 API 生图模型   |
| 素材库     | 图片与视频跨项目复用，加入画布后自动选中并定位                  |
| 视频生成   | 本地 MiniMax H3，支持参考图、声音与台词、480P / 720P 和多种比例 |
| 统一设置   | 生图配置、本地环境、视频写词 AI、生成图片保存位置               |

可以同时提交和追踪多个任务。API 生图最多同时执行 3 个请求，额外请求排队；单个本地 ComfyUI 按队列执行图片和视频任务。工作台中的多任务管理不等于单张显卡同时进行多路模型推理。

## 快速启动

### Windows：双击启动

1. 下载仓库源码并解压到一个可写文件夹，或通过 Git 获取：

   ```powershell
   git clone https://github.com/xuhang0310/qwen-image-gallery.git
   cd qwen-image-gallery
   ```

2. 双击项目根目录的 `start-workbench.bat`，也可以在 PowerShell 中运行：

   ```powershell
   ./start-workbench.bat
   ```

3. 等待依赖安装和页面构建完成，浏览器会打开 [http://127.0.0.1:3788](http://127.0.0.1:3788)。
4. 在左侧 **设置 → 生图模型与本地环境** 中选择 API 模型，或配置本地 ComfyUI。

启动脚本会复用符合要求的 Node.js；没有合适版本时，从 Node.js 官方站点下载 Node.js 24 便携版并校验 SHA-256，放在 `.run/node`，不替换系统安装。首次启动需要访问 `nodejs.org` 和 npm 注册表。

这个入口先启动工作台网页服务。ComfyUI 安装、模型下载和试生成在设置界面中完成；只使用 API 生图时无需安装 ComfyUI。

### 已安装 Node.js：手动启动

需要 **Node.js 24.14 或更新版本**。服务使用 Node.js 内置 SQLite 和下载代理支持。

```powershell
npm ci
npm start
```

`npm start` 会先构建 Vue 前端，再启动网页服务。完成后访问 [http://127.0.0.1:3788](http://127.0.0.1:3788)。

网页服务默认只监听本机回环地址。自动准备运行环境、ComfyUI 自动安装和图形文件夹选择器面向 Windows；其他系统可使用手动启动方式，连接已配置好的本机 ComfyUI 或生图 API。

## 配置生图引擎

| 使用方式 | 本机需要什么                                            | 首次配置入口                                        |
| -------- | ------------------------------------------------------- | --------------------------------------------------- |
| API 生图 | 工作台运行环境、可用的 API 地址与密钥                   | 设置 → 生图模型与本地环境 → API 模型                |
| 本地生图 | 工作台运行环境、ComfyUI、匹配的 Python / PyTorch 和模型 | 设置 → 生图模型与本地环境 → 本地模型 → 配置本地环境 |

工作台、所有项目和无限画布共用 API 地址、密钥与本地环境配置。工作台和画布顶部仍可快捷切换生图引擎；画布顶部的选择用于新节点，已有节点保留各自的模型。

### API 生图

1. 打开 **设置 → 生图模型与本地环境**，选择 **API 模型**。
2. 填写完整 API 基础地址，例如 `https://api.openai.com/v1`，以及该服务的密钥。
3. 选择模型，可先点击 **保存并获取模型列表** 检查服务连接。
4. 点击 **保存并使用 API**，返回工作台或画布生成图片。

当前代码提供以下模型选项：

| 界面名称                 | 提交的模型 ID            |
| ------------------------ | ------------------------ |
| GPT Image 2              | `gpt-image-2`            |
| GPT Image 2.5 · Flare    | `gpt-image-2.5-flare`    |
| GPT Image 2.5 · Sunburst | `gpt-image-2.5-sunburst` |

这些是项目支持的模型 ID，是否可用取决于所连接服务和账户权限。低于 2 系列的模型不在当前可选范围；日期快照不再显示为单独选项，旧记录在重试时映射到同系列的当前模型。

**接口要求**

- `/models`：供连接检查和模型列表读取使用。
- `/images/generations`：接收文生图 JSON 请求。
- `/images/edits`：接收带 `image[]` 参考图的 multipart 请求。
- 返回 `data[0].b64_json`。当前工作台不以远程图片 URL 作为生成结果。

地址需要使用 HTTPS，本机回环服务可使用 HTTP。第三方兼容服务会收到 `response_format=b64_json`；直连 `api.openai.com` 时不额外传这个字段。模型列表检查不会提交生图请求，实际生图权限仍需通过生成任务确认。

**比例与质量**

界面根据节点模型选择对应的尺寸和质量预设，并将 `size`、`quality` 发送给服务。GPT Image 2 的草稿、标准、高质量对应 `low`、`medium`、`high`；2.5 配置另提供 `auto`、`xhigh`、`max` 选项。参数表位于 [shared/api-image.json](shared/api-image.json)。

API 返回图片按实际像素展示，不通过裁剪或本地超分把结果强行改成请求尺寸。兼容服务若忽略参数，应检查其上游与转发实现。API 模式不使用本地随机种子；反向提示词作为“请避免以下内容”补充到主提示词。

**任务行为**

每次提交固定该任务的模型、参数、API 地址和密钥；之后切换配置不会改变已提交请求。历史重试使用原任务的引擎和模型，以及当前服务配置。

排队任务取消后不再发起请求；执行中的任务取消会停止本机等待，远端仍可能完成并计费。默认等待超时为 15 分钟。网页服务重启后，中断的 API 任务标记为失败，不自动重新调用生图接口。

密钥保存在本机 `.data/api-engine.json`，不返回给浏览器，也不进入任务、画布或项目导出。更换服务地址时需要重新填写对应密钥或清除旧密钥。该配置文件含明文密钥，不应上传到公开仓库。

### 本地 Qwen Image

进入 **设置 → 生图模型与本地环境 → 本地模型 → 配置本地环境**，按四步完成配置。

#### 1. 检查这台电脑

界面读取显卡、驱动、显存、系统内存、磁盘空间、Python / PyTorch 与 ComfyUI 状态。点击重新检测后，已有 Python 环境会进行一次 CUDA 运算检查。

当前向导对本地 Qwen 模型的建议为：

| 项目         | 向导建议                                                      |
| ------------ | ------------------------------------------------------------- |
| 自动安装支持 | Windows x64、NVIDIA RTX 显卡                                  |
| 显存         | 8 GB 需要实测，建议低显存模式和快速档；12 GB 及以上有更多余量 |
| 系统内存     | 建议 32 GB 或更多，模型卸载到内存时需要额外空间               |
| 安装盘空间   | 至少预留 25 GB，生成素材另占空间                              |
| 首次联网     | 需要访问 GitHub、Hugging Face 和 npm 注册表                   |

这些是本项目的检查阈值与使用建议。硬件检测通过、文件存在或节点就绪，都不能替代最后的实际试生成。

#### 2. 配置 ComfyUI

- **没有安装**：选择安装父目录，点击下载并安装。向导新建 `ComfyUI_windows_portable`，包含 Python、PyTorch 和 ComfyUI，不覆盖已有安装。安装清单固定在 [shared/setup-manifest.json](shared/setup-manifest.json)。
- **已有安装**：填写服务地址、数据目录、`main.py` 和 Python 可执行文件的完整路径，然后保存。数据目录应包含 `models`、`input`、`output`；桌面版的程序目录和数据目录可能不同。

工作台默认连接 `http://127.0.0.1:8000`；独立启动的便携版常用 `http://127.0.0.1:8188`，以引擎窗口显示的地址为准。便携版目录结构和启动方式见 [ComfyUI 官方安装文档](https://docs.comfy.org/installation/comfyui_portable_windows)。

无法使用自动安装的硬件，可按 [ComfyUI 系统要求](https://docs.comfy.org/installation/system_requirements) 手动准备环境，再连接已有本机服务。

#### 3. 准备模型

默认三个必需模型合计约 14.2 GB。界面显示安装路径、来源和许可，支持逐个下载、断点续传、完整 SHA-256 校验以及核对已有文件。

以下路径相对于 **ComfyUI 数据目录**：

| 用途               | 模型文件                                  | 安装目录                  |
| ------------------ | ----------------------------------------- | ------------------------- |
| 主模型             | `qwen_image_2.1_int8_convrot.safetensors` | `models/diffusion_models` |
| 文本与参考图编码器 | `qwen3vl_8b_w4a8.safetensors`             | `models/text_encoders`    |
| 图片 VAE           | `qwen_image_2.1_vae_bf16.safetensors`     | `models/vae`              |
| 可选超分模型       | `4x-UltraSharp.pth`                       | `models/upscale_models`   |

前三项来自 [Comfy-Org/Qwen-Image-2.1](https://huggingface.co/Comfy-Org/Qwen-Image-2.1)。UltraSharp 只用于超分档，普通生成不需要。使用各模型前应阅读对应模型来源的许可。

自定义模型需要自行提供，并修改模型配置；自动下载只支持安装清单中的文件。使用外部模型目录时，应在 ComfyUI 配置额外模型搜索路径。

#### 4. 启动与验证

启动或连接 ComfyUI，确认必需模型被识别、Qwen 节点齐全，然后点击 **开始试生成**。向导会通过实际工作流生成一张 1024 × 1024 图片，读取、解码并检查输出尺寸，显示结果和耗时；查看画面并确认后才显示已验证。

本地生图质量为 **快速 / 精细 / 超分**。快速最长边为 1024 像素，精细最长边为 1472–1664 像素；超分在精细结果上使用超分模型。实际比例与像素配置位于 [shared/config.json](shared/config.json)。

安装和模型下载失败后可重试；未完成下载会保留分片。已有不匹配的完整文件不会被覆盖，需先移到备份位置。关闭配置界面不会停止后台安装任务，结束网页服务进程则会中断。

下载代理可在本地环境向导的 **下载网络设置** 中保存，也可使用启动环境的 `HTTP_PROXY` / `HTTPS_PROXY`。本机 ComfyUI 连接绕过代理。低显存设置在下一次由工作台启动引擎时生效。

## 使用工作台与项目画布

### 图像工作台

在左侧选择 **工作台**，切换文生图或图生图，填写提示词并设置画面比例、质量后生成。图生图一次使用一张参考图，可选择文件或拖入生成面板。

输入支持静态 PNG、JPEG、WebP，每张不超过 10 MB。上传内容超过像素限制、损坏或格式不支持时会显示错误。

生成期间可以继续提交其他任务。最近任务中可查看结果、重试或取消；结果区可下载原图。工作台生成的图片进入图片库，打开画布时不会自动把所有图片加入。

### 项目中心

在 **项目中心** 新建项目后进入空白画布。每个项目独立保存节点、连线、平移和缩放，图片库与视频库在所有项目中共用。

- 支持搜索、重命名，以及导出当前项目。
- 导入 JSON 会创建新项目，不覆盖当前画布。
- 已提交任务继续被追踪，可以切换项目；正在提交或准备任务时需等待。
- 删除项目只删除该项目画布，素材与生成记录保留；至少保留一个项目。
- 旧版本的单画布首次升级时迁移为“默认项目”。

### 无限画布

右键创建文字或图片节点，也可拖入本地图片。将图片节点连入文字节点后，它作为该文字节点的参考图；每个文字节点使用一张参考图。

文字节点底部可选择 **本地 Qwen** 或 **GPT Image 2 系列 API** 模型，再设置比例、质量并生成。不同节点可以使用不同模型，结果自动创建图片节点和连线。

右侧素材库的 **放入画布** 会添加并定位节点；素材已在当前画布时显示 **定位节点**，重复点击不会增加副本。图片和视频均可通过素材库放入画布。

图片节点可放大预览、作为下一次编辑的参考图，或连接视频节点。编辑成功后替换原节点图片，保留位置与连线；失败或取消时保留原图。

**清空画布** 移除当前项目的节点与连线并重置视角，保留素材库和已提交任务。本次页面打开期间，添加新节点前可撤销清空；清空状态会自动保存。

| 操作               | 方式                                   |
| ------------------ | -------------------------------------- |
| 平移画布           | 拖动空白区域                           |
| 缩放               | 滚轮或顶部缩放按钮                     |
| 文字节点生成       | `Enter`                                |
| 文字节点换行       | `Shift + Enter`                        |
| 工作台快捷生成     | `Ctrl / Cmd + Enter`                   |
| 删除选中节点或连线 | `Delete` / `Backspace`，输入框内不生效 |
| 适配全部节点       | 顶部“适配全部”或画布快捷键 `1`         |
| 恢复 100% 缩放     | 顶部“100%”或画布快捷键 `0`             |

## 生成视频

视频通过本地 ComfyUI 的 MiniMax H3 工作流生成，独立于当前生图引擎。切换到 API 生图不会把视频转为 API 生成。本地环境向导只准备 Qwen 生图模型，视频模型与自定义节点需另行安装。

### 准备视频环境

当前默认使用 `beta3-lite` 工作流。先准备支持 MiniMax H3 的 ComfyUI，安装工作流所需的 [T8 音视频节点](https://github.com/T8mars/comfyui-minimax-h3-audio-T8)、[KJNodes](https://github.com/kijai/ComfyUI-KJNodes)，以及注意力分块、BlockCache 等对应节点。相关工作流与节点来源见 [MiniMax H3 工作流合集](https://github.com/YixuAn-13/minimax-h3-comfyui-all-in-one)。安装方法与依赖以节点仓库为准，完成后重启 ComfyUI；SageAttention 等扩展需匹配自己的 Python、PyTorch、CUDA 和显卡环境。

默认 Beta_3_Lite 工作流使用以下文件：

| 模型                                                                   | 安装目录                  |
| ---------------------------------------------------------------------- | ------------------------- |
| `10Eros_Max_h3_TURBO_ref2va_beta2_int8_convrot_skip_edges.safetensors` | `models/diffusion_models` |
| `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors`                         | `models/text_encoders`    |
| `minimax_h3_video_vae_int8_convrot.safetensors`                        | `models/vae`              |
| `minimax_h3_audio_vae_fp32.safetensors`                                | `models/vae`              |

主模型来源为 [cicalooo/10Eros-Max-h3-int8-convrot](https://huggingface.co/cicalooo/10Eros-Max-h3-int8-convrot)，其余模型和基础环境可参考 [ComfyUI MiniMax H3 指南](https://docs.comfy.org/tutorials/video/minimax/minimax-h3)。视频依赖和模型空间应另行预留，Qwen 向导的磁盘与显存建议不作为视频运行保证。

仓库提供 `scripts/download-beta3-model.py` 下载固定版本主模型，支持续传与 SHA-256 校验。脚本当前将 `TARGET` 写为 `D:/comfyui/models/diffusion_models`，在其他电脑使用前需要改成自己的模型目录；脚本依赖 Python `requests`，不会安装其余模型或节点。

基础工作流保留在 `workflows/minimax-h3.json`，默认工作流位于 `workflows/minimax-h3-beta3-lite.json`。设置 `VIDEO_WORKFLOW=base` 或 `beta3-lite` 后重启网页服务可切换；基础工作流主模型使用 `minimax_h3_fl2va_pruned_int8_convrot.safetensors`，与默认主模型不同。

中文场景转换使用本地 CPU 翻译。需要在指定 Python 环境中准备 PyTorch、Transformers、SentencePiece、sacremoses，并将 [Helsinki-NLP/opus-mt-zh-en](https://huggingface.co/Helsinki-NLP/opus-mt-zh-en) 的完整模型与分词器文件放到 `.data/video-translation`。可通过 `VIDEO_TRANSLATOR_PYTHON`、`VIDEO_TRANSLATOR_MODEL` 指定解释器与权重目录；运行时只读取本地文件，不自动下载。未准备翻译环境时，可先使用英文画面描述测试。

### 从画布生成

1. 在画布顶部添加 **视频节点**，或从图片节点选择使用这张图生成视频。
2. 连接或添加参考图，选择每张图的用途为人物或场景。默认工作流支持最多 9 张参考图，基础工作流使用单张参考图。
3. 填写镜头、人物与动作描述；需要声音时明确写台词，例如：`人物面向镜头微笑挥手，人物说：“大家好。”`。
4. 选择质量、比例和时长，可点击 **AI 优化提示词** 后检查回填内容，也可直接生成。
5. 点击 **生成视频**，结果节点显示任务状态和真实采样进度；完成后可播放、下载 MP4，并从视频库找回。

| 质量 | 横版 16:9  | 竖版 9:16  | 方形 1:1  |
| ---- | ---------- | ---------- | --------- |
| 480P | 854 × 480  | 480 × 854  | 480 × 480 |
| 720P | 1280 × 720 | 720 × 1280 | 720 × 720 |

时长可选 4、6、8、10 秒，按模型帧数网格处理，24 fps 的实际输出约为 4.46、6.58、8.00、10.13 秒。先用 480P 短视频验证环境，再提高质量、时长或参考图数量。

纯场景描述不会自动变成口播。需要说话、唱歌或画外音时应明确标注；中文台词与歌词保留原文，中文场景说明转换为英文。翻译失败会停止提交。提示词是生成引导，人物还原、动作、声音和实际耗时需检查成片。

### 视频写词 AI

在 **设置 → 视频写词 AI** 配置文字模型。可以复用生图服务的地址与密钥，也可使用独立、兼容 Chat Completions 的 API 或本机 `/v1` 服务。文字模型需要单独选择，生图模型列表不代替文字模型配置。

点击优化后，AI 将描述扩成可编辑的表演方案，保留指定台词。该操作只发送文字与视频参数，不上传参考图片，也不提交视频生成任务；使用远程文字模型时按对应服务计费。

修改描述、参考图用途、时长或参数后，生成前会重新整理内容。节点可查看原始提示词及放大当前提示词；后台模型提示词随项目保存。旧版提示词确认卡片仍兼容，可编辑时间分段、更新预览并确认生成；刷新不会自动确认或提交。

## 图片保存与数据迁移

### 设置生成图片的保存位置

进入 **设置 → 图片保存位置**，选择文件夹或填写完整路径，点击 **保存位置**。保存前会创建目录并检查写入权限。

默认位置为项目的 `.data/generated-images`；指定 `DATA_DIR` 时使用该目录下的 `generated-images`。新提交的本地与 API 图片使用同一个设置，按任务 ID 命名，例如 `<任务ID>-1.png`。

该目录保存原图副本，不取代工作台内部素材地址。已有图片、已提交任务的目标路径不会随设置改变；视频仍由 ComfyUI 保存。目标文件夹无法写入时，任务结果保留，界面提示保存失败。

### 本机数据位置

下表以默认 `.data` 为例：

| 位置                                                       | 内容                                            |
| ---------------------------------------------------------- | ----------------------------------------------- |
| `.data/workbench.sqlite`                                   | 生成任务、项目、节点、连线和各项目版本          |
| `.data/api-images/input`                                   | 上传到工作台的参考图片                          |
| `.data/api-images/output`                                  | API 生成的图片原始缓存                          |
| `.data/api-images/thumbnails`、`.data/thumbnails`          | API 图片与本地图片缩略图缓存                    |
| `.data/generated-images` 或指定保存目录                    | 自动保存的生成图片副本                          |
| `.data/runtime.json`                                       | 本机 ComfyUI 路径、地址、代理与低显存设置       |
| `.data/api-engine.json`                                    | API 生图配置，可能含明文密钥                    |
| `.data/video-prompt-ai.json`                               | 视频写词 AI 配置，独立配置时可能含明文密钥      |
| `.data/workbench-settings.json`                            | 生成图片的默认保存目录                          |
| `.data/video-translation`                                  | 本地视频场景翻译权重                            |
| ComfyUI 的 `input/qwen-workbench`、`output/qwen-workbench` | 本地参考图与生成图片                            |
| ComfyUI 的 `output/video/qwen-workbench`                   | 视频文件                                        |
| `.run`                                                     | 启动日志、服务进程记录、便携 Node.js 等运行文件 |

浏览器还保留项目备份用于恢复未完成的保存。SQLite 对每个项目进行版本检查；多个窗口修改同一项目时，旧版本保存会被拒绝，先导出当前画布，再重新载入最新数据。

### 换一台电脑

1. 等待任务结束并关闭旧电脑的工作台；复制数据库时也应停止其他访问它的进程。
2. 在新电脑获取源码，重新启动并配置 API 或本地环境，不复制 `node_modules`、`dist`、`.run`。
3. 保留项目与记录时，复制 `.data/workbench.sqlite` 及同名 `-wal`、`-shm` 文件（若存在），并复制 `.data/api-images`。
4. 保留本地图片和视频时，复制旧 ComfyUI 的 `input/qwen-workbench`、`output/qwen-workbench`、`output/video/qwen-workbench`。已有模型可复制相应 `models` 子目录。
5. 自动保存的图片副本在自选目录中，需要单独复制。需要中文视频场景转换时，一并准备翻译模型和 Python 依赖。
6. 在新电脑重新填写 ComfyUI 路径、API 配置和图片保存位置。旧电脑的路径配置不能直接作为新电脑的配置使用。

**项目 JSON 只包含参数和媒体引用，不包含图片、视频实体。** 导出 JSON 可备份画布结构；跨电脑恢复完整素材仍需要复制对应文件目录。密钥不随项目导出迁移，建议在新电脑界面重新填写。

## 服务管理与开发

### Windows 服务管理

完成本地环境配置后，可在项目根目录运行：

```powershell
./services.bat status all
./services.bat start all
./services.bat restart web
./services.bat stop all
```

| 参数                                    | 含义                       |
| --------------------------------------- | -------------------------- |
| `start` / `stop` / `restart` / `status` | 启动、停止、重启、检查状态 |
| `web`                                   | 只管理工作台网页服务       |
| `comfy`                                 | 只管理本地 ComfyUI         |
| `all`                                   | 管理两者                   |

只使用 API 生图时使用 `start web`，不需要启动 ComfyUI。`restart-all.bat` 会重启网页服务和本地引擎。停止或重启前应等待生成任务结束。

服务管理器按确切脚本路径识别进程，不会停止其他程序占用的端口。相对路径手动启动的旧进程可能无法识别，应在原终端结束后改用服务管理器。设置向导的停止按钮只管理当前网页服务自己启动的引擎，外部启动的 ComfyUI 应从原窗口管理。

日志位于 `.run/web.log`、`.run/web.err.log`。通过服务管理器启动的引擎日志在 `.run/comfyui.log`、`.run/comfyui.err.log`；通过设置向导启动的引擎日志在 `.data/comfy-engine.log`。

### 配置与环境变量

静态生图参数位于 `shared/config.json`，API 模型与参数位于 `shared/api-image.json`，安装下载清单位于 `shared/setup-manifest.json`。修改静态模型或采样配置后需要重启服务。

| 环境变量                                            | 用途                                               |
| --------------------------------------------------- | -------------------------------------------------- |
| `PORT`                                              | 网页服务端口，默认 `3788`                          |
| `COMFYUI_BASE_URL`                                  | 初始 ComfyUI 地址，默认 `http://127.0.0.1:8000`    |
| `DATA_DIR`                                          | 工作台数据目录，默认项目下的 `.data`               |
| `WORKBENCH_CONFIG`                                  | 自定义 JSON 配置文件路径，与默认模型和采样字段合并 |
| `COMFY_TIMEOUT_MS`                                  | 默认 ComfyUI 请求超时，单位毫秒                    |
| `OPENAI_BASE_URL`、`OPENAI_API_KEY`                 | 生图 API 的初始地址与对应密钥                      |
| `GPT_IMAGE_TIMEOUT_MS`                              | 单次 API 生图等待超时，默认 `900000` 毫秒          |
| `VIDEO_WORKFLOW`                                    | 视频预设：`beta3-lite` 或 `base`，优先于静态配置   |
| `VIDEO_TRANSLATOR_PYTHON`、`VIDEO_TRANSLATOR_MODEL` | 本地场景翻译的 Python 与模型目录                   |
| `VIDEO_PROMPT_MODEL`                                | 视频写词 AI 的初始文字模型 ID                      |
| `VIDEO_PROMPT_BASE_URL`、`VIDEO_PROMPT_API_KEY`     | 独立视频写词服务的初始地址与对应密钥               |
| `HTTP_PROXY`、`HTTPS_PROXY`                         | 启动环境的下载与联网代理                           |
| `WORKBENCH_NO_BROWSER`                              | 设为 `1` 时，双击启动入口不自动打开浏览器          |

环境变量提供初始配置；已经保存的本机路径与 API 配置优先。API 环境密钥只用于匹配的初始服务地址。程序不自动读取 `.env` 文件，需要在启动终端或系统环境中设置变量。

## 常见问题

### ComfyUI 未连接，无法本地生图

到 **设置 → 生图模型与本地环境 → 本地模型 → 配置本地环境** 检查服务地址和引擎状态。确认 ComfyUI 已启动，端口与设置一致，并且必要模型与节点被识别。只使用 API 时切换到 API 模型，不需要等待本地引擎上线。

### 模型文件已经下载，仍提示未就绪

检查文件名和目录是否与界面一致、ComfyUI 是否使用了正确数据目录；通过“校验已有模型”检查完整性。外部模型路径需要配置到 ComfyUI 的搜索路径。文件被识别后仍需实际试生成。

### 提示显存不足或生成很慢

检查是否有其他程序占用显存，启用低显存模式后重新启动引擎，并先用快速生图档或 480P 短视频测试。低显存模式会增加系统内存占用与耗时，本地队列中的任务按顺序推理。

### API 检查成功，但生成失败或参数不生效

模型列表接口可访问不代表生图权限可用。检查模型 ID、额度、`/images/generations` / `/images/edits` 支持情况，以及是否返回 `b64_json`。尺寸或质量被忽略时核对服务端上游与转发配置；工作台保留实际返回图像。

### 进入画布没有自动出现历史图片

这是当前行为：每个项目独立保存画布，历史素材在右侧图片库或视频库中。点击“放入画布”添加；显示“定位节点”表示素材已经在当前画布。

### 刷新后任务能否恢复

当前项目、页面和画布视角会恢复。本地任务可重新查询 ComfyUI 状态，浏览器刷新不会主动取消已提交任务；仅刷新浏览器时 API 任务也继续由网页服务处理。若网页服务进程重启，中断的 API 请求不会自动重新提交。

### 图片没有写入设置的文件夹

检查目录写入权限和结果区的保存提示。新位置只对之后提交的图片生效，不移动旧图片，也不改变已提交任务的目标位置。视频保存目录仍属于 ComfyUI。

### 换电脑导入项目后看不到素材

项目 JSON 没有媒体实体。按数据迁移说明复制 API 图片缓存、本地图片和视频目录，并在新电脑重新配置本地环境。单独复制自动保存的图片副本不会自动修复原有媒体引用。

### 首次启动或下载失败

查看 `.run/web.err.log` 或配置向导的任务日志，并检查 Node.js、npm、GitHub、Hugging Face 的网络连接。下载需要代理时在启动环境或本地环境向导中填写；损坏的完整文件需先备份移走再重试。
